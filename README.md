# Renewed Vision Church Community Website

A modern, welcoming, and inspiring web application for **Renewed Vision Church Community**.

## Features & Structure

- **Announcement Bar**: Service schedules, online livestream times, and welcoming notes.
- **Header & Navbar**: Brand logo with cross icon, smooth-scrolling navigation (`About Us`, `Ministries`, `Community Life`, `Stories`), and quick actions (`Plan a Visit`, `Connect & Prayer`).
- **Hero Carousel**: High-impact modern sanctuary and community imagery with auto-slide transitions, welcoming vision statement, and sub-hero tiles.
- **Core Values**: "Rooted in Christ. Bound in Love. Sent to Serve."
- **Ministries**: Worship & Creative Arts, Life Groups & Fellowship, NextGen Youth & Kids, Compassion & Outreach.
- **What to Expect**: First-time visitor roadmap detailing Sunday arrival, children's check-in, worship service, and community lounge.
- **Inspirational Invitation**: Full-width parallax banner with a glassmorphism card welcoming seekers and families.
- **Community Life Gallery**: High-resolution gallery capturing baptisms, praise, fellowship, kids activities, and outreach.
- **Member Stories**: Testimonies from church members sharing experiences of faith, hope, and community.
- **Connect & Plan Your Visit**: Integrated inquiry and prayer request form with WhatsApp and direct response support.
- **The Weekly Vision**: Newsletter sign-up for weekly devotionals and community announcements.
- **Footer**: Campus location, service hours, pastoral contacts, ministry links, and giving options.

## Getting Started

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
